Casino la maldad es una aplicación desarrollada en Python que busca recrear la
experiencia de un casino virtual de manera simple y entretenida mediante una interfaz
gráfica interactiva. El objetivo del proyecto es permitir que el usuario pueda
registrarse dentro del sistema, administrar su dinero virtual y participar en diferentes
juegos de azar donde podrá apostar fichas y obtener ganancias o pérdidas
dependiendo de los resultados.

Al iniciar la aplicación, el jugador deberá ingresar su nombre para registrarse en el
sistema. Una vez registrado, recibirá una cantidad inicial de dinero virtual que podrá
utilizar dentro del casino. Este dinero podrá ser administrado en la caja del casino,
también conocida como la jaula del cajero, donde el jugador podrá cambiar su dinero
por fichas para realizar apuestas en los juegos disponibles o convertir nuevamente las
fichas en dinero cuando lo desee.

El sistema contará con una interfaz gráfica que permitirá al jugador navegar entre
las diferentes secciones del casino, consultar su saldo, seleccionar un juego y
realizar apuestas. Además, cada juego tendrá su propia pantalla donde se mostrarán
los elementos visuales necesarios para el desarrollo de la partida. También se incluirán
animaciones simples, por ejemplo, al repartir cartas o al simular una carrera, con el
fin de hacer la experiencia más dinámica y comprensible para el usuario.

En el Blackjack, el jugador competirá contra el sistema intentando obtener una
puntuación lo más cercana posible a 21 sin pasarse. El sistema repartirá cartas al
jugador y al crupier, y el jugador podrá decidir si desea pedir otra carta o quedarse con
su mano actual. Al finalizar la ronda, se compararán los valores de las manos para
determinar si el jugador gana o pierde la apuesta.

En el Poker, se implementará una versión simplificada donde el jugador se enfrentará a
un oponente controlado por el sistema. Ambos recibirán cartas y el sistema evaluará
las combinaciones obtenidas para determinar cuál mano es superior. Dependiendo del
resultado, el jugador ganará o perderá las fichas apostadas.

El tercer juego será Carreras de caballos, donde el jugador podrá apostar por uno de
varios caballos participantes en una carrera. Una vez realizada la apuesta, el sistema
simulará la carrera mediante un proceso aleatorio que determinará cuál caballo llega
primero a la meta. Si el caballo elegido por el jugador resulta ganador, el sistema
entregará la recompensa correspondiente.

Durante toda la experiencia, el sistema será responsable de gestionar las apuestas
realizadas por el jugador, actualizar su saldo de fichas y mostrar los resultados de cada
partida. De esta manera, el proyecto busca simular el funcionamiento básico de un
casino virtual mediante una aplicación interactiva que combine varios juegos dentro de
una misma plataforma.
